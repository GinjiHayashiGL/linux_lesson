# chmod.c 解説

ファイルのパーミッションを変更する `chmod` コマンドの簡易実装。

## 概要

```
./chmod <モード（8進数）> <ファイル名> [ファイル名 ...]
```

`argv[1]` に 8 進数のパーミッション値（例: `644`、`755`）を指定し、以降の引数で列挙したファイルに一括適用する。

## 関数

### `main`

```c
int main(int argc, char *argv[])
```

```c
int mode;
int i;
```
- `mode` は `strtol` で変換した数値パーミッション値を保持する。
- `i` はファイル引数を順に処理するループカウンタ。

```c
if (argc < 2) {
    fprintf(stderr, "no mode given\n");
    exit(1);
}
```
- モード引数が指定されていない場合はエラーを標準エラー出力に出して終了する。
- `fprintf(FILE *stream, const char *format, ...)` — フォーマット文字列を `stream` に書き出す。`stderr` へ出力することでリダイレクト時もエラーメッセージが端末に残る。エラー時は負値を返す。
- ファイル引数がゼロ本（`argc == 2`）の場合はモード解析だけ行いループを実行しない設計で、エラーにはならない。

```c
mode = strtol(argv[1], NULL, 8);
```
- `strtol(const char *nptr, char **endptr, int base)` — 文字列 `nptr` を基数 `base` の整数に変換して返す。`endptr` が非 `NULL` の場合、変換できなかった最初の文字のアドレスを格納する。オーバーフロー時は `LONG_MAX` または `LONG_MIN` を返す。
- `base = 8` を指定して 8 進数として解析する。Unix のパーミッションは伝統的に 8 進数で表現するため（例: `0644` = `rw-r--r--`）、この基数が必須となる。
- `endptr = NULL` を渡しているので変換失敗の検出は行っていない。不正な文字列を渡すと `0` になり、すべてのパーミッションが剥奪される点に注意。

```c
for (i = 2; i < argc; i++) {
    if (chmod(argv[i], mode) < 0) {
        perror(argv[i]);
    }
}
```
- `argv[2]` から順にすべてのファイルに対して `chmod` を呼ぶ。
- `chmod(const char *pathname, mode_t mode)` — `pathname` のパーミッションビットを `mode` で指定した値に変更する。成功時は `0`、失敗時は `-1` を返し `errno` をセットする。
  - 変更できるのはファイルの所有者またはスーパーユーザーのみ。それ以外は失敗して `errno = EPERM`。
  - `pathname` がシンボリックリンクの場合はリンク先ファイルのパーミッションを変更する。リンク自体のパーミッションは変更できない。
  - ディレクトリにも適用でき、その場合は検索・読み取り・書き込みパーミッションが変わる。
- 失敗時は `perror` でエラーを出力するが `exit` は呼ばない。1 つのファイルが失敗しても残りのファイルの処理を継続する設計。`rm.c` が失敗時に即 `exit` するのとは対照的。
- `perror(const char *s)` — `s` の後ろにコロンを付け、`errno` に対応するシステムエラーメッセージを標準エラー出力に書き出す。失敗したファイル名（`argv[i]`）を渡すことで原因をユーザーに伝える。

```c
exit(0);
```
- 個々のファイルへの適用が失敗していてもステータス `0` で終了する。厳密なエラー伝播が必要な場合は失敗フラグを保持して終了ステータスに反映すべきだが、本実装はシンプルさを優先している。

## 処理の流れ

```
main
 ├─ 引数チェック（argc < 2）
 │   └─ エラー時: fprintf(stderr, ...) → exit(1)
 ├─ strtol(argv[1], NULL, 8)    // 8進数文字列 → 数値パーミッション
 └─ for (i = 2; i < argc; i++)
     ├─ chmod(argv[i], mode)    // パーミッション変更
     │   └─ 失敗時: perror(argv[i])  ※ exit しない
     └─ 次のファイルへ
 └─ exit(0)
```

## 関数・システムコール一覧

| 関数（またはシステムコール） | シグネチャ | 説明 |
|------------------------------|-----------|------|
| `chmod` | `int chmod(const char *pathname, mode_t mode)` | `pathname` のパーミッションビットを `mode` に変更する。成功時 `0`、失敗時 `-1` |
| `strtol` | `long strtol(const char *nptr, char **endptr, int base)` | 文字列を指定基数の整数に変換する。`base=8` で 8 進数解析 |
| `fprintf` | `int fprintf(FILE *stream, const char *format, ...)` | フォーマット文字列を指定ストリームに書き出す。エラー時は負値を返す |
| `perror` | `void perror(const char *s)` | `s` に続けて `errno` に対応するエラーメッセージを標準エラー出力に出力する |
| `exit` | `void exit(int status)` | プログラムを終了する。`0` で正常終了、非ゼロで異常終了 |
