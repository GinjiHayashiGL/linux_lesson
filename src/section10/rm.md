# rm.c 解説

ファイルを削除する `rm` コマンドの簡易実装。

## 概要

```
./rm <ファイル名> [ファイル名 ...]
```

1 つ以上のファイルを引数に取り、順に削除する。ディレクトリの削除は対象外。

---

## インクルードファイル

| ヘッダ | 概要 | 用途 |
|--------|------|------|
| `stdio.h` | 標準入出力ライブラリ | `fprintf`、`perror` |
| `stdlib.h` | 標準ユーティリティライブラリ | `exit`（プログラム終了） |
| `unistd.h` | POSIX API | `unlink`（ファイル削除システムコール） |

---

## 関数

### `main`

```c
int main(int argc, char *argv[])
```

```c
int i;
```
- ファイル引数を順に処理するループカウンタ。

```c
if (argc < 2) {
    fprintf(stderr, "%s: no arguments\n", argv[0]);
    exit(1);
}
```
- 削除対象のファイルが 1 つも指定されていない場合はエラーを標準エラー出力に出して終了する。
- `fprintf(FILE *stream, const char *format, ...)` — フォーマット文字列を `stream` に書き出す。`stderr` へ出力することで、リダイレクト時もエラーメッセージが端末に残る。エラー時は負値を返す。
- `argv[0]` をプレフィックスにすることで、どのコマンドが失敗したかユーザーが把握しやすくなる。

```c
for (i = 1; i < argc; i++) {
    if (unlink(argv[i]) < 0) {
        perror(argv[i]);
        exit(1);
    }
}
```
- `argv[1]` から順にすべての引数に対して `unlink` を呼ぶ。
- `unlink(const char *pathname)` — `pathname` が指すディレクトリエントリ（ハードリンク）を削除する。そのファイルへのハードリンクがすべて削除され、かつオープンしているプロセスが存在しない場合に限り、実際のデータブロックが解放される。成功時は `0`、失敗時は `-1` を返し `errno` をセットする。
  - シンボリックリンクを指定した場合はリンク自体が削除され、リンク先ファイルは影響を受けない。
  - ディレクトリを指定した場合は失敗する（`errno = EISDIR`）。ディレクトリ削除には `rmdir` を使う。
- 失敗時は `perror` でエラーメッセージを出力して即終了する。途中で失敗しても残りのファイルは削除しないシンプルな設計。
- `perror(const char *s)` — `s` の後ろにコロンを付け、`errno` に対応するシステムエラーメッセージを標準エラー出力に書き出す。失敗したファイル名（`argv[i]`）を `s` に渡すことで、どのファイルが原因かをユーザーに伝える。

```c
exit(0);
```
- すべてのファイルの削除に成功したらステータス `0` で終了する。

---

## 処理の流れ

```
main
 ├─ 引数チェック（argc < 2）
 │   └─ エラー時: fprintf(stderr, ...) → exit(1)
 └─ for (i = 1; i < argc; i++)
     ├─ unlink(argv[i])   // ディレクトリエントリを削除
     │   └─ 失敗時: perror(argv[i]) → exit(1)
     └─ 次のファイルへ
 └─ exit(0)
```

## 関数・システムコール一覧

| 関数（またはシステムコール） | シグネチャ | 説明 |
|------------------------------|-----------|------|
| `unlink` | `int unlink(const char *pathname)` | ディレクトリエントリを削除する。ハードリンクがゼロになりオープン中プロセスもなければデータも解放される。成功時 `0`、失敗時 `-1` |
| `fprintf` | `int fprintf(FILE *stream, const char *format, ...)` | フォーマット文字列を指定ストリームに書き出す。エラー時は負値を返す |
| `perror` | `void perror(const char *s)` | `s` に続けて `errno` に対応するエラーメッセージを標準エラー出力に出力する |
| `exit` | `void exit(int status)` | プログラムを終了する。`0` で正常終了、非ゼロで異常終了 |
