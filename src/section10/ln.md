# ln.c 解説

`ln` コマンドの簡易実装。既存のファイルに対してハードリンクを作成する。

## 概要

```
./ln <既存ファイル> <新しいリンク名>
```

引数はちょうど 2 つ必要。`argv[1]` が既存ファイル、`argv[2]` が作成するリンクのパスになる。

---

## インクルードファイル

| ヘッダ | 概要 | 用途 |
|--------|------|------|
| `stdio.h` | 標準入出力ライブラリ | `fprintf`、`perror` |
| `stdlib.h` | 標準ユーティリティライブラリ | `exit`（プログラム終了） |
| `unistd.h` | POSIX API 定義 | `link` システムコール |

---

## 関数

### `main`

```c
int main(int argc, char *argv[])
```

```c
if (argc != 3) {
    fprintf(stderr, "%s: wrong arguments\n", argv[0]);
    exit(1);
}
```
- `link` には必ず 2 つの引数（既存ファイルと新リンク名）が必要なので、`argc != 3` で過不足を同時にチェックする。`mkdir`/`rmdir` のように複数引数を受け付ける設計ではないため、`< 2` ではなく `!= 3` を使っている。
- `fprintf(FILE *stream, const char *format, ...)` — フォーマット付きでストリームに書き出す。`argv[0]` にプログラム名を埋め込むことで、どのコマンドがエラーを出したか分かりやすいメッセージになる。エラー時は負の値を返す。

```c
if (link(argv[1], argv[2]) < 0) {
    perror(argv[1]);
    exit(1);
}
```
- `link(const char *oldpath, const char *newpath)` — `oldpath` に対するハードリンクを `newpath` として作成するシステムコール。成功時は `0`、失敗時は `-1` を返し `errno` をセットする。
  - ハードリンクとは、同一ファイルシステム上の既存の inode に対して別名（ディレクトリエントリ）を追加する操作。どちらのパス名からも同じデータにアクセスでき、一方を削除してももう一方は残る。
  - ディレクトリへのハードリンクはカーネルが禁止している（ファイルシステムのループを防ぐため）。
  - `oldpath` と `newpath` が異なるファイルシステムにある場合も失敗する（`EXDEV`）。
- `perror` の引数に `argv[1]`（既存ファイル名）を渡しているのは、失敗の原因がリンク元に起因することが多いためで、どのファイルで問題が起きたかをユーザーに伝える。
- `perror(const char *s)` — `s` に続けて `errno` に対応するエラーメッセージを標準エラー出力に出力する。戻り値はない。

```c
exit(0);
```
- リンク作成に成功した場合、正常終了ステータスでプロセスを終了する。
- `exit(int status)` — プロセスを終了する。`0` で正常終了、非ゼロで異常終了を示す。

---

## 処理の流れ

```
main
 ├─ 引数チェック（argc != 3）
 │   └─ エラー: fprintf(stderr, ...) → exit(1)
 ├─ link(argv[1], argv[2])
 │   ├─ 成功（戻り値 0）: exit(0)
 │   └─ 失敗（戻り値 -1）: perror(argv[1]) → exit(1)
 └─ exit(0)
```

## 関数・システムコール一覧

| 関数（またはシステムコール） | シグネチャ | 説明 |
|------------------------------|-----------|------|
| `link` | `int link(const char *oldpath, const char *newpath)` | `oldpath` のハードリンクを `newpath` として作成する。成功時 `0`、失敗時 `-1`（`errno` セット） |
| `fprintf` | `int fprintf(FILE *stream, const char *format, ...)` | フォーマット付きでストリームに書き出す。エラー時は負の値 |
| `perror` | `void perror(const char *s)` | `s` に続けて `errno` に対応するエラーメッセージを標準エラー出力に出力する |
| `exit` | `void exit(int status)` | プログラムを終了する。`0` で正常終了、非ゼロで異常終了 |
