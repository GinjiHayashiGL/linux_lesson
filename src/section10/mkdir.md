# mkdir.c 解説

`mkdir` コマンドの簡易実装。コマンドライン引数に指定したディレクトリを順に作成する。

## 概要

```
./mkdir <ディレクトリ名> [ディレクトリ名 ...]
```

複数のディレクトリをまとめて作成できる。いずれかの作成に失敗した時点で終了する。

## 関数

### `main`

```c
int main(int argc, char *argv[])
```

```c
int i;
```
- `i` は引数ループのカウンタ。`argv[1]` 以降を順に処理するために使う。

```c
if (argc < 2) {
    fprintf(stderr, "%s: no arguments\n", argv[0]);
    exit(1);
}
```
- ディレクトリ名が 1 つも指定されていない場合、プログラム名付きのエラーメッセージを標準エラー出力に出して終了する。
- `fprintf(FILE *stream, const char *format, ...)` — フォーマット付きでストリームに書き出す。`argv[0]` にプログラム名を埋め込むことで、どのコマンドがエラーを出したか一目で分かるメッセージになる。エラー時は負の値を返す。
- `fputs` ではなく `fprintf` を使っているのは、`argv[0]`（プログラム名）を動的に埋め込む必要があるため。

```c
for (i = 1; i < argc; i++) {
    if (mkdir(argv[i], 0777) < 0) {
        perror(argv[i]);
        exit(1);
    }
}
```
- `argv[1]` から末尾まで順にループし、各引数をディレクトリ名として `mkdir` を呼ぶ。
- `mkdir(const char *pathname, mode_t mode)` — 新しいディレクトリを作成するシステムコール。`pathname` に指定したパスにディレクトリを作る。成功時は `0`、失敗時は `-1` を返し `errno` をセットする。
  - `mode` には `0777`（所有者・グループ・その他すべてに読み書き実行権限）を指定しているが、実際に設定されるパーミッションはプロセスの **umask** によってマスクされる。典型的な umask `022` であれば `0755` になる。
- `mkdir` が `-1` を返したとき（作成失敗）は `perror` でエラーメッセージを出して即終了する。
- `perror(const char *s)` — `s`（ここではディレクトリ名）に続けて `errno` に対応するエラーメッセージを標準エラー出力に出力する。戻り値はない。失敗の原因（権限不足、既存ディレクトリとの衝突など）をユーザーに伝えるのに適している。

```c
exit(0);
```
- すべてのディレクトリ作成に成功した場合、正常終了ステータスでプロセスを終了する。
- `exit(int status)` — プロセスを終了する。`0` で正常終了、非ゼロで異常終了を示す。

## 処理の流れ

```
main
 ├─ 引数チェック（argc < 2）
 │   └─ エラー: fprintf(stderr, ...) → exit(1)
 └─ for (i = 1; i < argc; i++)
     ├─ mkdir(argv[i], 0777)
     │   ├─ 成功（戻り値 0）: 次のループへ
     │   └─ 失敗（戻り値 -1）: perror(argv[i]) → exit(1)
     └─ すべて成功: exit(0)
```

## 関数・システムコール一覧

| 関数（またはシステムコール） | シグネチャ | 説明 |
|------------------------------|-----------|------|
| `mkdir` | `int mkdir(const char *pathname, mode_t mode)` | ディレクトリを作成する。成功時 `0`、失敗時 `-1`（`errno` セット） |
| `fprintf` | `int fprintf(FILE *stream, const char *format, ...)` | フォーマット付きでストリームに書き出す。エラー時は負の値 |
| `perror` | `void perror(const char *s)` | `s` に続けて `errno` に対応するエラーメッセージを標準エラー出力に出力する |
| `exit` | `void exit(int status)` | プログラムを終了する。`0` で正常終了、非ゼロで異常終了 |
