# mv.c 解説

ファイルやディレクトリを移動・改名する `mv` コマンドの簡易実装。

## 概要

```
./mv <移動元パス> <移動先パス>
```

`argv[1]` を `argv[2]` に改名（移動）する。同一ファイルシステム内であればデータのコピーは発生しない。

---

## インクルードファイル

| ヘッダ | 概要 | 用途 |
|--------|------|------|
| `stdio.h` | 標準入出力ライブラリ | `fprintf`、`perror` |
| `stdlib.h` | 標準ユーティリティライブラリ | `exit`（プログラム終了） |
| `unistd.h` | POSIX API | `rename` の宣言を含む `<stdio.h>` が提供するが、POSIX 準拠のヘッダとして明示的にインクルード |

## 関数

### `main`

```c
int main(int argc, char *argv[])
```

```c
if (argc != 3) {
    fprintf(stderr, "%s: wrong arguments\n", argv[0]);
    exit(1);
}
```
- 引数がちょうど 2 つ（移動元・移動先）でなければエラーを標準エラー出力に出して終了する。
- `fprintf(FILE *stream, const char *format, ...)` — フォーマット文字列を `stream` に書き出す。`stderr` へ出力することで、リダイレクト時もエラーメッセージが端末に残る。エラー時は負値を返す。
- `argv[0]` をプレフィックスにすることで、どのコマンドが失敗したかユーザーが把握しやすくなる。

```c
if (rename(argv[1], argv[2]) < 0) {
    perror(argv[1]);
    exit(1);
}
```
- `rename(const char *oldpath, const char *newpath)` — `oldpath` のディレクトリエントリを `newpath` に原子的に改名する。成功時は `0`、失敗時は `-1` を返し `errno` をセットする。
  - **原子性**: カーネルが 1 つのシステムコールで古いエントリの削除と新しいエントリの作成を行うため、途中でプロセスがクラッシュしても中間状態が残らない。
  - **同一ファイルシステム内**: inode を付け替えるだけなのでデータのコピーが発生せず、ファイルサイズに関わらず O(1) で完了する。
  - **ファイルシステムをまたぐ場合**: 失敗して `errno = EXDEV` がセットされる。その場合はコピー後に元ファイルを削除する必要がある（本実装では非対応）。
  - **移動先が既に存在する場合**: ファイルであれば上書き削除する。ディレクトリであれば空の場合のみ置き換え、空でなければ失敗する（`errno = ENOTEMPTY`）。
- 失敗時は `perror` で移動元パスとエラーメッセージを出力して終了する。
- `perror(const char *s)` — `s` の後ろにコロンを付け、`errno` に対応するシステムエラーメッセージを標準エラー出力に書き出す。失敗した対象（`argv[1]`）を渡すことで、何が原因かユーザーに伝える。

```c
exit(0);
```
- 改名に成功したらステータス `0` で終了する。

---

## 処理の流れ

```
main
 ├─ 引数チェック（argc != 3）
 │   └─ エラー時: fprintf(stderr, ...) → exit(1)
 ├─ rename(argv[1], argv[2])   // ディレクトリエントリを原子的に改名
 │   └─ 失敗時: perror(argv[1]) → exit(1)
 └─ exit(0)
```

---

## 関数・システムコール一覧

| 関数（またはシステムコール） | シグネチャ | 説明 |
|------------------------------|-----------|------|
| `rename` | `int rename(const char *oldpath, const char *newpath)` | `oldpath` を `newpath` に原子的に改名する。同一FS内ならデータコピー不要。成功時 `0`、失敗時 `-1` |
| `fprintf` | `int fprintf(FILE *stream, const char *format, ...)` | フォーマット文字列を指定ストリームに書き出す。エラー時は負値を返す |
| `perror` | `void perror(const char *s)` | `s` に続けて `errno` に対応するエラーメッセージを標準エラー出力に出力する |
| `exit` | `void exit(int status)` | プログラムを終了する。`0` で正常終了、非ゼロで異常終了 |
