# rmdir.c 解説

`rmdir` コマンドの簡易実装。コマンドライン引数に指定した**空の**ディレクトリを順に削除する。`mkdir.c` と対をなす実装で、構造はほぼ同一だが使用するシステムコールと引数が異なる。

## 概要

```
./rmdir <ディレクトリ名> [ディレクトリ名 ...]
```

複数のディレクトリをまとめて削除できる。いずれかの削除に失敗した時点で終了する。

---

## インクルードファイル

| ヘッダ | 概要 | 用途 |
|--------|------|------|
| `stdio.h` | 標準入出力ライブラリ | `fprintf`、`perror` |
| `stdlib.h` | 標準ユーティリティライブラリ | `exit`（プログラム終了） |
| `unistd.h` | POSIX API 定義 | `rmdir` システムコール |

## 関数

### `main`

```c
int main(int argc, char *argv[])
```

```c
int i;
```
- `i` は引数ループのカウンタ。`argv[1]` 以降を順に処理するために使う。

```c
if (argc < 2) {
    fprintf(stderr, "%s: no arguments\n", argv[0]);
    exit(1);
}
```
- ディレクトリ名が 1 つも指定されていない場合、プログラム名付きのエラーメッセージを標準エラー出力に出して終了する。
- `fprintf(FILE *stream, const char *format, ...)` — フォーマット付きでストリームに書き出す。`argv[0]` にプログラム名を埋め込むことで、どのコマンドがエラーを出したか分かりやすいメッセージになる。エラー時は負の値を返す。

```c
for (i = 1; i < argc; i++) {
    if (rmdir(argv[i]) < 0) {
        perror(argv[i]);
        exit(1);
    }
}
```
- `argv[1]` から末尾まで順にループし、各引数を対象に `rmdir` を呼ぶ。
- `rmdir(const char *pathname)` — 空のディレクトリを削除するシステムコール。成功時は `0`、失敗時は `-1` を返し `errno` をセットする。
  - `mkdir` と異なりモード引数がない。削除にパーミッション設定は不要なため。
  - ディレクトリが**空でない**場合は `ENOTEMPTY` エラーになり削除に失敗する。これはカーネルによる安全策で、意図しないファイル消失を防ぐ。
  - ディレクトリが存在しない、権限がない、通常ファイルを指定するなどの場合も失敗する。
- `rmdir` が `-1` を返したとき（削除失敗）は `perror` でエラーメッセージを出して即終了する。
- `perror(const char *s)` — `s`（ここではディレクトリ名）に続けて `errno` に対応するエラーメッセージを標準エラー出力に出力する。戻り値はない。失敗原因（空でない、権限不足など）をユーザーに伝えるのに適している。

```c
exit(0);
```
- すべてのディレクトリ削除に成功した場合、正常終了ステータスでプロセスを終了する。
- `exit(int status)` — プロセスを終了する。`0` で正常終了、非ゼロで異常終了を示す。

---

## 処理の流れ

```
main
 ├─ 引数チェック（argc < 2）
 │   └─ エラー: fprintf(stderr, ...) → exit(1)
 └─ for (i = 1; i < argc; i++)
     ├─ rmdir(argv[i])
     │   ├─ 成功（戻り値 0）: 次のループへ
     │   └─ 失敗（戻り値 -1）: perror(argv[i]) → exit(1)
     └─ すべて成功: exit(0)
```

## 関数・システムコール一覧

| 関数（またはシステムコール） | シグネチャ | 説明 |
|------------------------------|-----------|------|
| `rmdir` | `int rmdir(const char *pathname)` | 空のディレクトリを削除する。成功時 `0`、失敗時 `-1`（`errno` セット） |
| `fprintf` | `int fprintf(FILE *stream, const char *format, ...)` | フォーマット付きでストリームに書き出す。エラー時は負の値 |
| `perror` | `void perror(const char *s)` | `s` に続けて `errno` に対応するエラーメッセージを標準エラー出力に出力する |
| `exit` | `void exit(int status)` | プログラムを終了する。`0` で正常終了、非ゼロで異常終了 |

## mkdir.c との比較

| 観点 | mkdir.c | rmdir.c |
|------|---------|---------|
| 目的 | ディレクトリを作成する | 空のディレクトリを削除する |
| システムコール | `mkdir(pathname, mode)` | `rmdir(pathname)` |
| モード引数 | `0777`（umask でマスクされる） | なし（削除にパーミッション設定は不要） |
| インクルード | `sys/stat.h`、`sys/types.h` | `unistd.h` |
| 主な失敗原因 | 既存パスとの衝突、権限不足 | ディレクトリが空でない、権限不足、対象が存在しない |
