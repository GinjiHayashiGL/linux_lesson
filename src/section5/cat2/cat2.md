# cat2.c 解説

`cat` コマンドの簡易実装。指定したファイルの内容を標準出力に書き出す。cat.c（システムコール版）と異なり、標準ライブラリの `FILE` 型を使った実装。

## 概要

```
./cat2 <ファイル名> [ファイル名 ...]
```

---

## インクルードファイル

| ヘッダ | 概要 | 用途 |
|--------|------|------|
| `stdio.h` | 標準入出力ライブラリ。C言語で最も基本的なI/O関数群を提供する | `fopen`、`fgetc`、`fclose`、`putchar`、`perror` |
| `stdlib.h` | 標準ユーティリティライブラリ。メモリ管理・プロセス制御・変換関数を提供する | `exit`（プログラム終了） |

---

## 関数

### `main`

```c
int main(int argc, char *argv[])
```

```c
int i;
```
- ループカウンタ。引数リストを順番に処理するために使う。

```c
for (i = 1; i < argc; i++) {
```
- `i = 1` から始めるのは `argv[0]` がプログラム名であるため。
- `argv[1]` 以降の各ファイルパスを順番に処理する。
- cat.c と異なりファイル数チェックがないため、引数なしで実行した場合は何もせず正常終了する。

```c
FILE *f;
int c;
```
- `FILE *f` はファイルストリームへのポインタ。標準ライブラリが管理するバッファ付きI/Oの窓口。
- `int c` は `fgetc` の戻り値を受け取る変数。`char` ではなく `int` を使うのは、EOF（`-1`）と通常のバイト値（0〜255）を区別するため。

```c
f = fopen(argv[i], "r");
if (!f) {
    perror(argv[i]);
    exit(1);
}
```
- `fopen` でファイルをテキストモード（`"r"`）で開く。失敗時は `NULL` を返す。
- 失敗した場合は `perror` でエラーメッセージを出力し、`exit(1)` で異常終了する。

```c
while ((c = fgetc(f)) != EOF) {
    if (putchar(c) < 0) exit(1);
}
```
- `fgetc(f)` はファイルから1バイト読み込み、`int` として返す。ファイル末尾またはエラー時は `EOF`（= `-1`）を返す。
- `putchar(c)` は1バイトを標準出力に書き出す。エラー時は `EOF`（負の値）を返す。
- 書き込みエラーが発生した場合は `exit(1)` で異常終了する。

```c
fclose(f);
```
- `fclose` でファイルストリームを閉じ、内部バッファをフラッシュしてOSにファイルディスクリプタを返却する。
- cat.c の `close` と異なり、戻り値のチェックを行っていない。

```c
exit(0);
```
- すべてのファイル処理が正常に完了したことを示す正常終了。

## 処理の流れ

```
main
 └─ for (各ファイル引数)
     ├─ fopen(argv[i], "r")     // ファイルを開く
     ├─ loop:
     │   ├─ fgetc(f)            // 1バイト読む
     │   └─ putchar(c)          // 標準出力に1バイト書く
     └─ fclose(f)               // ファイルを閉じる
```

---

## 標準ライブラリ関数一覧

| 関数 | シグネチャ | 説明 |
|------|-----------|------|
| `fopen` | `FILE *fopen(const char *path, const char *mode)` | ファイルを開いてストリームを返す。失敗時は `NULL` |
| `fgetc` | `int fgetc(FILE *stream)` | ストリームから1バイト読み込む。EOF またはエラー時は `EOF` |
| `putchar` | `int putchar(int c)` | 標準出力に1バイト書き出す。エラー時は `EOF` |
| `fclose` | `int fclose(FILE *stream)` | ストリームを閉じてバッファをフラッシュする。エラーで `EOF` |
| `perror` | `void perror(const char *s)` | `s` に続けて `errno` に対応するエラーメッセージを標準エラー出力に出力する |

## cat.c（システムコール版）との比較

| 観点 | cat.c（システムコール版） | cat2.c（標準ライブラリ版） |
|------|--------------------------|--------------------------|
| I/O の単位 | 最大 2048 バイトのバッファ読み込み | 1バイトずつ読み込み |
| 使用する関数 | `open` / `read` / `write` / `close` | `fopen` / `fgetc` / `putchar` / `fclose` |
| バッファリング | 自前で管理 | 標準ライブラリが内部で管理 |
| 移植性 | POSIX 準拠環境が必要 | C標準ライブラリのみで動作 |
| コード量 | 多め（エラー処理含む） | 少なくシンプル |

POSIX のシステムコールを直接使う cat.c に対し、cat2.c は標準ライブラリの `FILE` 型ベースのI/Oを使うため、よりシンプルで移植性が高い。ただし1バイトずつ処理するため、大きなファイルではオーバーヘッドが生じる場合がある。
