# cat.c 解説

`cat` コマンドの簡易実装。指定したファイルの内容を標準出力に書き出す。

## 概要

```
./cat <ファイル名> [ファイル名 ...]
```

---

## インクルードファイル

| ヘッダ | 概要 | 用途 |
|--------|------|------|
| `stdio.h` | 標準入出力ライブラリ。C言語で最も基本的なI/O関数群を提供する | `fprintf`（エラーメッセージ出力）、`perror`（システムエラー出力） |
| `stdlib.h` | 標準ユーティリティライブラリ。メモリ管理・プロセス制御・変換関数を提供する | `exit`（プログラム終了） |
| `unistd.h` | POSIX標準のシステムコールラッパー。OSが提供する基本操作へのアクセスを提供する | `read`、`write`、`close`、`STDOUT_FILENO`（標準出力のファイルディスクリプタ番号 = 1） |
| `sys/types.h` | システムレベルで使われる基本型（`pid_t`、`off_t` など）を定義する | `open` などのシステムコールで使われる型の定義を取り込む |
| `sys/stat.h` | ファイルのメタデータ（パーミッション・種別など）に関する定数・構造体を定義する | `open` 時のモード定数（`S_IRUSR` 等）の定義を取り込む |
| `fcntl.h` | ファイル制御に関するフラグ・関数を定義する | `O_RDONLY`（読み取り専用フラグ）などの `open` フラグ |

## 関数

### `main`

```c
int main(int argc, char *argv[])
```

```c
int i;
```
- ループカウンタ。引数リストを順番に処理するために使う。

```c
if (argc < 2) {
    fprintf(stderr, "%s: file name not given\n", argv[0]);
    exit(1);
}
```
- `argc` はプログラム名を含むコマンドライン引数の総数。`argc < 2` はファイル名が1つも渡されていない状態を意味する。
- `fprintf(stderr, ...)` でエラーメッセージを標準エラー出力（ファイルディスクリプタ 2）に書く。`argv[0]` はプログラム名（例: `./cat`）。
- `exit(1)` で異常終了。慣習として、正常終了は `0`、異常終了は非ゼロの値を返す。

```c
for (i = 1; i < argc; i++) {
    do_cat(argv[i]);
}
```
- `i = 1` から始めるのは `argv[0]` がプログラム名であるため。
- `argv[1]` 以降の各ファイルパスを `do_cat` に渡して順番に処理する。

```c
exit(0);
```
- すべてのファイル処理が正常に完了したことを示す正常終了。

### `do_cat`

```c
static void do_cat(const char *path)
```
- `static` により、この関数はこのファイル内からしか呼び出せない（外部リンケージなし）。
- `const char *path` はファイルパスの文字列。`const` により関数内でパスを書き換えないことを保証する。

```c
int fd;
```
- ファイルディスクリプタを格納する変数。OSがオープンしたファイルを識別するための非負整数。`0`=標準入力、`1`=標準出力、`2`=標準エラー出力は予約済みのため、通常は 3 以上の値が割り当てられる。

```c
unsigned char buf[BUFFER_SIZE];
```
- 読み込みデータを一時的に保持するバッファ。`unsigned char` を使うことでバイナリファイルも含め、あらゆるバイト値（0〜255）を符号なしで扱える。`BUFFER_SIZE` は 2048。

```c
int n;
```
- `read` の戻り値（実際に読み込んだバイト数）を格納する変数。

```c
fd = open(path, O_RDONLY);
if (fd < 0) die(path);
```
- `open` システムコールでファイルをオープンする。`O_RDONLY` は読み取り専用モード。
- 戻り値が負（通常は `-1`）の場合はファイルが存在しない・権限がないなどのエラーを意味し、`die` を呼び出して終了する。

```c
for (;;) {
```
- 無限ループ。EOF に達するか、エラーが発生したときに `break` または `die` で抜ける。

```c
    n = read(fd, buf, sizeof buf);
```
- `read` システムコールで最大 `sizeof buf`（= 2048）バイトを `buf` に読み込む。
- 戻り値 `n` は実際に読み込んだバイト数。ファイル末尾では `0`、エラー時は `-1` を返す。

```c
    if (n < 0) die(path);
```
- `read` がエラーを返した場合（ディスクエラーなど）に `die` で異常終了する。

```c
    if (n == 0) break;
```
- `n == 0` は EOF（ファイルの終端）を意味する。ループを抜けてファイルを閉じる処理へ進む。

```c
    if (write(STDOUT_FILENO, buf, n) < 0) die(path);
```
- `write` システムコールで `buf` の内容を `n` バイト分、標準出力（`STDOUT_FILENO` = 1）に書き出す。
- `n` を指定することで、バッファの未使用領域を出力しない。
- 戻り値が負の場合（標準出力への書き込みエラー）は `die` で終了する。

```c
if (close(fd) < 0) die(path);
```
- `close` でファイルディスクリプタを解放する。ディスクリプタはOS資源であるため、使い終わったら必ず閉じる。
- 戻り値が負の場合はクローズ失敗（バッファのフラッシュエラーなど）を意味し、`die` で終了する。

---

### `die`

```c
static void die(const char *s)
```
- エラー発生時に呼ばれる共通のエラー終了関数。`static` により外部から呼び出せない。

```c
perror(s);
```
- `perror` は `s` の文字列（ファイルパスなど）に続けて、グローバル変数 `errno` の値に対応するシステムエラーメッセージを標準エラー出力に出力する。
- 例: `open` が失敗した場合 → `./foo.txt: No such file or directory`

```c
exit(1);
```
- 異常終了コード `1` でプログラムを即座に終了する。

## 処理の流れ

```
main
 └─ for (各ファイル引数)
     └─ do_cat(path)
         ├─ open(path, O_RDONLY)   // ファイルを開く
         ├─ loop:
         │   ├─ read(fd, buf, 2048) // 最大2048バイト読む
         │   └─ write(STDOUT_FILENO, buf, n) // 標準出力に書く
         └─ close(fd)              // ファイルを閉じる
```

## システムコール一覧

| システムコール | シグネチャ | 説明 |
|--------------|-----------|------|
| `open` | `int open(const char *path, int flags)` | ファイルを開いてファイルディスクリプタを返す。失敗時は `-1` |
| `read` | `ssize_t read(int fd, void *buf, size_t count)` | `fd` から最大 `count` バイト読み込む。EOF で `0`、エラーで `-1` |
| `write` | `ssize_t write(int fd, const void *buf, size_t count)` | `fd` へ `count` バイト書き出す。エラーで `-1` |
| `close` | `int close(int fd)` | ファイルディスクリプタを解放する。エラーで `-1` |

標準ライブラリの `fopen` / `fread` ではなく、POSIX のシステムコールを直接使っている点がポイント。バッファリングなしで OS に直接アクセスするため、動作がより明示的で低レベルな制御が可能。
